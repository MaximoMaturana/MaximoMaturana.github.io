Overview

A game built from scratch

Trust Issues is a 2D Pygame game developed entirely in Python, without game engines or pre-built frameworks. Every mechanic — movement, collision, rendering, level design — was implemented directly in code.

The project was a deep dive into game development fundamentals: game loops, sprite management, state machines, and user interaction — all applied to a real playable game with original artwork and levels.

Tech Stack

  • 🐍 Python 3
  • 🎮 Pygame
  • 🖼️ Custom 2D Assets
  • 🗺️ Level Design
  • 🔄 Game Loop Architecture
